# Affordable Plumbing Repair Services — Website

Professional business website for **APRS** — Sheldon's plumbing company serving the New Orleans, LA area.

## 🔧 Live Site
Deployed via GitHub Pages: [View Live](#)

## 📁 Project Structure
```
affordable-plumbing/
├── index.html          # Main single-page website
├── assets/
│   ├── style.css       # Stylesheet
│   └── van.png         # Company van photo
└── README.md
```

## 🚀 Tech Stack
- Pure HTML5 / CSS3 / Vanilla JS
- Google Fonts (Inter + Montserrat)
- Font Awesome 6 icons
- Deployed on GitHub Pages

## ⭐ Features
- Responsive, mobile-first design
- Hero section with van photo
- Services grid (8 service cards)
- Customer reviews from Google
- Contact section with click-to-call
- Scroll fade-in animations
- Active nav highlighting
