# Affordable Plumbing Repair Services — Website

Professional business website for **APRS** — Sheldon's plumbing company serving the New Orleans, LA area.

## 🔧 Live Site
Deployed via GitHub Pages: [https://farmadvisorar-ux.github.io/affordable-plumbing/](https://farmadvisorar-ux.github.io/affordable-plumbing/)

## 📁 Project Structure
```
affordable-plumbing/
├── index.html          # Main single-page website with OpenGraph & Twitter metadata
├── assets/
│   ├── style.css       # Stylesheet
│   ├── van.png         # Company van photo
│   └── og-image.png    # 1200x630 Social preview card for link sharing
└── README.md
```

## 🚀 Tech Stack
- Pure HTML5 / CSS3 / Vanilla JS
- Open Graph & Twitter Cards for social media / SMS / iMessage link previews
- Google Fonts (Inter + Montserrat)
- Font Awesome 6 icons
- Deployed on GitHub Pages

## ⭐ Features
- Rich social preview link with custom 1200x630 banner
- Responsive, mobile-first design
- Hero section with van photo and rating badge
- Services grid (8 service cards)
- Customer reviews from Google
- Contact section with click-to-call
- Scroll fade-in animations
- Active nav highlighting
